# MultiSport Edge AI

Multi-sport prediction and portfolio-analysis platform.

## Objective

Scan normalized bookmaker markets across multiple sports, score candidate selections with auditable analytical confidence, reject correlated or weak selections, and construct qualified 10–15 selection portfolios targeting approximately 1.45–1.60 combined decimal odds.

**Important:** analytical confidence is a model score, not a guaranteed probability of winning.

## MVP principles

- Multi-sport, not football-only.
- Separate calibrated probability from analytical confidence.
- Minimum candidate confidence defaults to 90/100.
- Never force a portfolio when insufficient qualified selections exist.
- Correlation controls prevent stacking dependent selections.
- Compare equivalent Betway and Sportingbet prices when permitted data is available.
- Preserve provider/raw data and an auditable settlement trail.
- Track individual-leg accuracy separately from accumulator performance.
- Results reconciliation is separate from bookmaker settlement rules.

## Initial sports

Football, tennis, basketball, rugby, cricket, ice hockey, baseball, volleyball, handball and table tennis.
